# لا تنسى

تطبيق Checklist شخصي مصمم بهوية «حِبْر» — يعمل بالكامل دون إنترنت، ويُحفظ كل شيء داخل متصفحك باستخدام LocalStorage.

## المميزات

- إنشاء قوائم غير محدودة (مشتريات، سفر، قبل الخروج من المنزل...)
- إضافة عناصر وتحديدها كمكتملة أو إلغاء التحديد
- حذف العناصر والقوائم مع نافذة تأكيد أنيقة
- إعادة تسمية القوائم وزر «إلغاء تحديد الكل»
- مؤشر تقدم دائري + شريط تقدم لكل قائمة
- تحية حسب وقت اليوم + إحصائيات سريعة في الرئيسية
- Dark Mode محفوظ محليًا (مصمم فعليًا وليس قلب ألوان)
- نوافذ حوار وToast مخصصة بدل alert/confirm التقليدية
- شاشة افتتاحية ببصمة المطوّر
- قسم «تواصل مع المشرف» (Instagram / WhatsApp)
- يعمل Offline 100% — لا تسجيل دخول، لا إعلانات، لا خادم

## طريقة التشغيل

1. حمّل الملفات الثلاثة في مجلد واحد.
2. افتح `index.html` بأي متصفح.
3. هذا كل شيء — التطبيق يعمل ويحفظ بياناته تلقائيًا.

> اختياري عبر خادم محلي:
> ```bash
> python3 -m http.server 8000
> ```

## نظام التصميم «حِبْر»

الهوية مبنية على متغيرات CSS في `:root` — لإعادة استخدامها في تطبيق آخر:
غيّر الألوان فقط (ورق/حبر/ختم) ويبقى الأسلوب كاملًا (أزرار، حركات، نوافذ، Toast).

- وضع النهار: ورق دافئ `#f6f1e7` × حبر `#221d15` × ختم كهرماني متدرج
- وضع الليل: حبر ليلي `#15120d` × نص ورقي
- خط: Cairo/Tajawal إن توفرت، مع بديل نظام offline

## كيف يعمل؟

- البيانات JSON في LocalStorage تحت المفتاح `latansa_v1` — والثيم تحت `latansa_theme`.
- النمط: **الحالة ← إعادة الرسم**. أي تغيير يعدّل الحالة ثم يعيد رسم الشاشة.
- النوافذ المخصصة تعمل بـ Promises بنفس سلوك confirm/prompt.
